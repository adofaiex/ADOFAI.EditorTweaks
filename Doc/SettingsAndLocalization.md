# 设置与本地化

设置只保存在本 Mod 自己的 UMM 设置文件中：

| 字段 | 默认值 | 作用 |
| --- | --- | --- |
| `EnableNumericDrag` | true | 启用数值拖动。 |
| `FloatStepPerPixel` | 0.1 | 浮点数每像素步长。 |
| `IntStepPerPixel` | 1 | 整数每像素步长。 |
| `MaxFloatingPoints` | 3 | 最大显示小数位。 |
| `EnableCameraRelativeDecorationDragFix` | true | 启用 Camera / CameraAspect 拖动修复。 |
| `EnableDecorationPivotFix` | true | 启用轴心修复。 |
| `DecorationMoveSnapStep` | 0.5 | 装饰移动吸附步长，0 表示关闭。 |
| `EnableVideoBackgroundSyncFix` | true | 启用普通游戏视频同步。 |
| `PersistEditorPreferences` | true | 即时保存官方编辑器偏好。 |
| `EnableImageLoadErrorDeduplication` | true | 去重缺图加载错误。 |

`Resources/localization.json` 只包含本项目设置面板和补丁状态所需文本。
