ADOFAI Editor Tweaks 用户手册

本手册随 Mod 功能一起维护。你可以按照下面的步骤直接使用各项功能，不需要了解任何内部原理。

功能概览

更顺手地改数值

在支持的数字输入框上按住鼠标右键左右拖动，即可连续调整数值。

更准确地移动装饰

改善相对摄像机装饰的拖动、轴心显示和移动吸附。

改善视频背景播放

从谱面中途开始播放时，减少视频背景与音乐、谱面进度不一致的问题。

直接处理谱面压缩包

可打开多种常见压缩包，并改善韩文、中文、日文等文件名的识别。

导出谱面视频

可选择纯净谱面画面或完整游戏画面，导出整首谱面或选中的一段。

手动同步设置

可以把当前设置上传到 Steam 云，也可以在另一台设备上下载。

安装、升级与停用

首次安装

  1. 确认游戏已经安装并能正常启动。
  2. 把发布包完整安装到游戏的 Mods 目录，不要只复制其中一个文件。
  3. 启动游戏，在 Mod 管理窗口中启用 ADOFAI Editor Tweaks。
  4. 进入编辑器后，在 UMM 设置中确认 Web 页面快捷键，默认是 Ctrl + Shift + E。
  5. 按下快捷键即可打开本机 Web 设置页；Mod 不会自动弹出浏览器。

升级

退出游戏后，用新版本完整覆盖旧版本目录。个人设置通常会保留；如果新版本增加了设置，会自动使用推荐默认值。

临时停用或卸载

临时停用时，在 Mod 管理窗口中关闭本 Mod。卸载时先退出游戏，再删除对应 Mod 目录。

功能兼容状态

游戏更新后，部分编辑器行为可能发生变化。设置页面中的“功能兼容状态”可以帮助你确认哪些功能仍能使用。

状态含义你需要做什么
可用该功能可以正常使用。无需处理。
不可用该功能暂时不兼容当前游戏版本。关闭对应功能并等待 Mod 更新。
因依赖功能不可用而停用该功能需要的另一项功能当前不可用。查看同一区域中先出现的不可用项目。
单项功能不可用不会让整个 Mod 停止工作，其他显示“可用”的功能仍可继续使用。

数值右键拖动

  1. 在编辑器中选中一个带数字设置的事件或装饰。
  2. 把鼠标放到支持的数字输入框上。
  3. 按住鼠标右键，向右拖动增大数值，向左拖动减小数值。
  4. 松开右键完成修改。

你可以在 Web 设置页的“数值拖动”模块中调整小数步进、整数步进和最多保留的小数位数。

拖动幅度不合适时，先降低“小数拖动步进”或“整数拖动步进”，再继续操作。

装饰编辑

移动相对摄像机的装饰

像移动普通装饰一样拖动即可。按住 Shift 可以限制到单一方向。

移动吸附

“装饰移动吸附精度”决定松开鼠标后的位置间隔。例如设为 0.5 时，位置会落在 0.5 的倍数上；设为 0 时关闭吸附。

轴心十字

选中装饰时，轴心标记会跟随装饰的实际显示位置，便于对齐和检查。

视频背景同步

启用“视频背景同步修复”后，从编辑器中途播放、从检查点开始或进行谱面渲染时，视频背景会尽量与当前音乐和谱面进度对齐。

如果谱面本身设置了视频偏移，请保留谱面作者给出的数值；本功能不会替你修改谱面文件。

如果视频文件损坏、无法播放或电脑解码压力过高，本功能不能修复文件本身。请先确认该视频在普通播放器中可以正常播放。

Web 设置页与快捷键

  • UMM 面板只保留 Web 页面快捷键录入，默认是 Ctrl + Shift + E。
  • 点击“录入快捷键”后按下新的组合键，保存 UMM 设置即可。
  • Web 设置页包含全部 Mod 设置、兼容性状态、云同步和谱面渲染进度。
  • 页面只连接本机地址，Mod 不会向局域网开放设置服务。
  • 渲染期间请在同一个 Web 页面查看进度；也可以按 Esc 紧急取消。

打开与导入压缩包

支持 ZIP、ADOZIP、RAR、7Z、TAR、GZ、BZ2、XZ、CAB，以及 TGZ、TBZ2、TXZ 等常见格式。

  1. 在游戏编辑器中选择打开谱面或导入谱面。
  2. 选择包含谱面和资源的压缩包。
  3. 等待导入完成，然后确认音乐、图片、视频等资源是否都能正常找到。
不要导入来源不明的压缩包。导入前建议保留原文件备份。

导出谱面包

  1. 先保存当前谱面，确认音乐、图片和视频都能在编辑器中正常使用。
  2. 使用游戏编辑器原有的导出功能。
  3. 选择保存位置并等待导出完成。
  4. 得到的文件仍是标准的 .adozip，可分享给未安装本 Mod 的玩家。

资源子目录和包含韩文、中文、日文的文件名会尽量保持原样。

旧 ZIP 文件名编码

大多数情况下保持“自动检测”即可。如果某个旧压缩包导入后仍然出现乱码，可以根据它最初使用的语言手动尝试：

选项适用情况
自动检测默认推荐，适合绝大多数压缩包。
CP949较旧的韩文 ZIP。
GB18030较旧的简体中文 ZIP。
Shift-JIS较旧的日文 ZIP。
CP437较旧的西文或 DOS ZIP。

修改后重新导入原压缩包。这个选项只影响下一次操作，不需要重启游戏。

选择画面模式

摄像机渲染 默认推荐

输出干净的谱面画面，不包含编辑器按钮、菜单和屏幕上的其他界面。

可以自由设置输出宽度和高度，适合普通谱面、投稿视频和高分辨率成品。

游戏画面渲染 兼容模式

输出当前游戏窗口真正显示的内容，包括谱面界面、编辑器界面、额外画面和屏幕效果。

成品分辨率跟随开始渲染时的游戏分辨率，宽度和高度无需另行设置。

使用游戏画面渲染时，请在开始前调整好游戏窗口大小。渲染期间不要改变分辨率、缩放窗口、最小化窗口或切换显示模式，否则本次渲染会停止。
渲染进度只显示在 Web 设置页中，不会被录入成品。需要取消时按 Esc。

完整渲染步骤

打开并检查谱面

先正常播放一小段，确认音乐、背景、视频和装饰都能正确显示。

选择画面捕获方式

普通谱面优先使用摄像机渲染；摄像机模式缺少内容时再改用游戏画面渲染。

设置输出选项

选择保存目录、帧率、结束后延迟停止秒数、是否显示判定文字，以及是否只渲染选中段落。

检查保存空间

高分辨率、较长谱面和较高帧率会占用更多临时空间与成品空间。

点击“开始渲染”

渲染期间不要关闭游戏，在同一个 Web 页面查看完整进度。

等待结果提示

完成、失败或取消后，页面顶部会显示明确结果和成品位置；失败或取消后也会恢复正常播放和输入。

渲染设置

设置建议
导出目录选择空间充足、容易找到的位置。
画面捕获方式默认使用摄像机渲染；特殊谱面再使用游戏画面渲染。
宽度与高度只用于摄像机渲染。常用为 1920×1080；也可选择 2K、4K、竖屏或超宽屏预设。
帧率60 适合大多数谱面；30 文件更小；120 更流畅但耗时和空间明显增加。
结束后延迟停止秒数保留谱面结尾动画和余音，默认值通常无需修改。
显示判定文字按成品需求决定是否保留 Perfect、Early、Late 等文字。
视频格式MP4 兼容性最好；MKV 或 MOV 可用于特殊工作流程。
音频格式AAC 适合日常分享；FLAC、ALAC 适合需要无损声音的成品。
性能档位“自动均衡”适合大多数电脑；遇到问题可尝试“CPU 兼容”。
渲染预览只影响摄像机渲染时游戏中的显示，不影响成品；游戏画面渲染始终显示正常游戏画面。
渲染开始后，所有会影响当前输出的设置都会暂时锁定。任务完成、失败或取消后，设置会自动恢复可编辑。
高级设置和专业参数建议保持默认。不了解其用途时，不要粘贴网络上的参数。

只渲染选中段落

  1. 在编辑器中连续框选至少两个砖块。
  2. 打开“仅渲染选中段落”。
  3. 确认 Web 渲染页中的范围和设置正确。
  4. 开始渲染。成品会从选区起点开始，并在选区终点结束。
片段渲染不会使用“结束后延迟停止秒数”。如需保留结尾，请把后面的砖块也加入选区。

渲染问题排查

现象建议处理
渲染按钮不可用确认已经加载可播放谱面，并查看“功能兼容状态”中的输入保护和谱面渲染是否可用。
成品缺少某些界面或特殊画面改用“游戏画面渲染（兼容模式）”。
游戏画面模式中途停止保持游戏窗口尺寸和显示模式不变，然后重新渲染。
视频背景不同步先确认谱面视频偏移正确，再重新打开谱面；不要在渲染途中拖动游戏进度。
成品卡顿或导出很慢降低分辨率或帧率，关闭其他占用较高的程序，或尝试“CPU 兼容”档位。
声音提前或延后先恢复默认设置重试；只有偏差始终固定时，才小幅调整音频同步偏移。
输出目录没有成品确认磁盘空间充足、目录可写，并查看游戏提示中的失败原因。

如果仍然无法解决，反馈时请附上游戏日志、谱面复现步骤，以及当前渲染工作目录中的 render.log。

Steam 云设置

上传设置存档

把当前 Mod 设置保存到 Steam 云。上传会替换之前保存的 Mod 设置。

下载设置存档

把 Steam 云中的 Mod 设置应用到当前电脑。下载前如有重要设置，建议先截图记录。

云同步是手动操作，不会在启动和退出游戏时自动覆盖设置。

常见问题

如何恢复默认设置？

设置页面工具模块提供“恢复全部默认”，会同时恢复功能开关、通用设置和渲染设置。

为什么游戏画面模式不能设置输出分辨率？

该模式会使用当前游戏分辨率。请先在游戏设置中调整好窗口或全屏分辨率，再开始渲染。

为什么摄像机模式不包含编辑器界面？

这是它的预期效果，适合输出干净的谱面视频。需要界面时请选择游戏画面模式。

导入后文件名仍然乱码怎么办？

把“旧版 ZIP 文件名编码”从自动检测改为压缩包对应的语言选项，然后重新导入原文件。

某个功能不可用会影响其他功能吗？

通常不会。以“功能兼容状态”为准，显示可用的项目仍可正常使用。

游戏更新后出现问题怎么办？

先查看功能兼容状态，并确认正在使用最新版 Mod。反馈时附上游戏版本、Mod 版本、日志和复现步骤。
